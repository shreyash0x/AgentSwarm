# AgentSwarm

AgentSwarm is planned as a Windows-first, installable CLI for coordinating real software-engineering agents with isolated workspaces, independent QA, and milestone-controlled GitHub operations.

This repository is currently at **Milestone 0 — GitHub Bootstrap**. The implementation is intentionally deferred so the repository foundation can be reviewed before coding begins.

## Reference projects

- Antigravity official interfaces will be validated before provider integration.
- OpenCode is a terminal UX benchmark and reference for interaction patterns.
- [REA](https://github.com/morluto/rea) is an optional authorized-analysis integration target. Its current setup and license will be verified before implementation.

## Planned work

See [docs/ROADMAP.md](docs/ROADMAP.md) for milestone sequencing and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the initial module boundaries.

## Development

The project targets Node.js 20 or newer and TypeScript. No runtime implementation has been added yet.
