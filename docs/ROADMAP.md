# SwarmForge roadmap

## Milestone 0 — GitHub Bootstrap

- Initialize `main` branch and repository metadata.
- Record GitHub remote and bootstrap commit.
- Establish milestone-only push policy.

## Milestone 1 — CLI foundation

- Installable CLI entry point.
- Validated configuration and local persistence.
- Terminal UI skeleton.

## Milestone 2 — Provider integration

- Validate official Antigravity installation and authentication surfaces.
- Implement supported ACP or headless integration.

## Milestone 3 — Multi-agent core

- Real sessions, task graph, concurrency, typed messages, and isolated worktrees.

## Milestone 4 — TUI

- Agent dashboard, selection, streaming, approvals, commands, and status.

## Milestone 5 — Reliability

- Independent QA, checkpoints, rollback, permissions, and recovery.

## Milestone 6 — Expanded integrations

- Optional REA analysis integration, MCP support, artifacts, and GitHub management.

## Milestone 7 — Release

- Verification, packaging, installation documentation, and release evidence.
